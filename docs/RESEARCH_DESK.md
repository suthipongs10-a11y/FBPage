# โต๊ะค้นคว้า (Research Desk) — ค้น สรุป เรียบเรียง ครบในระบบ

เพิ่มเมื่อ 27 กันยายน 2026 · อยู่บนสุดของหน้า **ห้องข่าว** (`/news`)
โค้ด: `apps/api/src/news/research.service.ts`, `packages/web-core/src/article.ts`, `packages/ai-core` (ตัวเลือก `webSearch`), `apps/web/components/research-desk.tsx`

ทำแบบเดียวกับที่เคยต้องไปสั่ง ChatGPT/Claude ข้างนอก แต่จบในโปรแกรมเรา — และผลลัพธ์เข้าทางตรวจเดียวกับ [การนำเข้า](CONTENT_IMPORT.md) (Template `fbpm-content-v1`) จึงได้กฎความปลอดภัยชุดเดียวกันทั้งหมด

```
หัวข้อ / ลิงก์ / ข้อความ
  → รวบรวมแหล่ง (4 โหมด ด้านล่าง)
  → AI บทบาท research สรุป: พาดหัว · สรุป · ประเด็นสำคัญ (ทุกข้อมีเลขแหล่ง [n]) · มุมที่น่าเล่า · จุดที่ยังไม่ชัด · ความเสี่ยง
  → คุณเลือก: มุม · สไตล์ · จำนวนโพสต์ · เพจ · AI ที่เขียน · แหล่งภาพ
  → AI บทบาท content เขียนโพสต์ (เขียนใหม่ ห้ามลอก ≥ 8 คำ, ไม่รู้ = [ต้องยืนยัน])
  → ตรวจข้อเท็จจริง: AI อีกรอบเทียบโพสต์กับประเด็น/แหล่ง — ข้อความที่หาหลักฐานไม่เจอถูกติด [ต้องยืนยัน: …] (ปุ่มอนุมัติปิดจนคนแก้)
  → ตรวจตาม Template (ที่มา, ซ้ำ, เพจ ฯลฯ) → ร่าง + การ์ด + รูป → แท็บ "เขียนแล้ว" → อนุมัติและตั้งเวลา
```

## 4 โหมดหาแหล่ง
| โหมด | ใช้เมื่อ | ต้องมี |
|---|---|---|
| **ค้นเว็บ (หลายแหล่ง)** | อยากได้ข่าว/ข้อมูลจากหลายเว็บ | คีย์ Tavily (ฟรี ~1,000 ครั้ง/เดือน) — AI บทบาท fast แตกคำค้นไทย/อังกฤษเพิ่ม 2–3 คำ แล้วอ่านบทความจริงสูงสุด 10 แหล่ง (เคารพ robots.txt, ≤ 1 คำขอ/วินาที) หน้าไหนอ่านไม่ได้ใช้เกริ่นจากผลค้นแทนและบอกให้เห็น |
| **ให้ AI ค้นเอง** | ถามเป็นประโยคยาว ๆ / อยากได้คำตอบเร็ว | คีย์ AI ที่ค้นเว็บได้: **Gemini** (Google Search), **Claude** (web search), **Perplexity** `sonar`/`sonar-pro` (เพิ่มได้จาก preset ใหม่), **OpenAI** รุ่น `gpt-5-search-api`/`gpt-4o-mini-search-preview`, **OpenRouter** — แหล่งที่ใช้คือ citations ที่ผู้ให้บริการส่งกลับจริง (ลิงก์ redirect ของ Google ถูกตามไปหาปลายทาง) ไม่ใช่ลิงก์ที่โมเดลพิมพ์เอง ถ้าไม่มี citations กลับมา = error ไม่เดา |
| **จากลิงก์** | มีบทความอยู่แล้ว | ไม่ต้องมีคีย์ค้น — วางลิงก์ ≤ 8 ลิงก์ ลิงก์ที่อ่านไม่ได้รายงานแยก |
| **จากข้อความ** | โน้ต, ข่าวประชาสัมพันธ์, รายละเอียดสินค้า | ไม่ต้องมีอะไรเพิ่ม — ได้โพสต์ของเพจเอง (ไม่มีบรรทัดที่มา) |

## โหมด "ให้ AI ค้นเอง" ทำงานสองขั้น
1. **ค้น** — ขอข้อค้นพบเป็นข้อความพร้อมเปิดเครื่องมือค้นเว็บ (ไม่บังคับ JSON) · ไม่ได้ citations → ลองอีกรอบด้วยคำสั่งให้ค้นก่อนตอบ
2. **จัดรูป** — ส่งข้อค้นพบ + รายการแหล่งจริง (อ่าน excerpt จากลิงก์) ให้โมเดลสรุปเป็น JSON ตามปกติ

เหตุผล: เจอจริงว่า Gemini 2.5 Pro เมื่อถูกบังคับให้ตอบ JSON พร้อมกัน จะตอบจากความจำโดยไม่ค้นเลย · ถ้า 2 รอบแล้วยังไม่ค้น → **สลับไปค้นผ่าน Tavily อัตโนมัติ** (ถ้ามีคีย์) และบอกในรายการแจ้งเตือน ไม่มีคีย์ = error พร้อมวิธีแก้ · แนะนำ `gemini-2.5-flash` สำหรับงานค้น (ถูกและค้นสม่ำเสมอกว่า)

## สไตล์การเขียน
ข่าวสั้น (hook + ย่อหน้าสั้น) · สรุปเป็นข้อ · เล่าเรื่อง · ถาม-ตอบ — เขียนได้ 1–5 โพสต์ต่อครั้ง แต่ละโพสต์คนละมุม · ใช้น้ำเสียง/กลุ่มผู้อ่าน/ข้อห้ามจากคลังความรู้แบรนด์

## เลือก AI ต่องาน (คุมค่าใช้จ่าย)
| ขั้น | บทบาท | แนะนำ |
|---|---|---|
| แตกคำค้น | fast | รุ่นถูกสุด (flash-lite / gpt-5-nano / deepseek) |
| สรุปประเด็น | research | โหมดค้นเว็บ/ลิงก์: รุ่นไหนก็ได้ · โหมด AI ค้นเอง: เลือกในช่อง "AI ที่ค้นเว็บได้" |
| เขียนโพสต์ | content | รุ่นที่เขียนไทยสวย (Claude / GPT-5) — เลือกรายครั้งได้ |
| ตรวจข้อเท็จจริง | research | ใช้ตัวเดียวกับสรุปได้ |

ค่าใช้จ่ายแต่ละงานบันทึกใน AiTaskLog และแสดงในหน้าผลลัพธ์ · **ค่าค้นเว็บของผู้ให้บริการ (เช่น Claude web search ~$10/1,000 ครั้ง, grounding ของ Gemini เกินโควตาฟรี) ไม่รวมในตัวเลขประมาณการ** — ดูบิลของผู้ให้บริการ

## ข้อมูลที่เก็บ
`ResearchBrief`: หัวข้อ, โหมด, สรุป (JSON), รายการแหล่ง = ชื่อเรื่อง + ลิงก์ + ชื่อเว็บ + วันที่ + **excerpt ≤ 1,200 ตัวอักษร** — เนื้อความเต็มของบทความใช้ในหน่วยความจำตอนสรุปเท่านั้น ไม่ลง DB · โพสต์ที่เขียนเข้า `ContentImport` (channel `research`) และผูก `NewsItem` (ป้าย "นำเข้า") ใช้กันซ้ำด้วย `dedupeKey` ต่อ brief+ชื่อเรื่อง (หลายโพสต์จากแหล่งเดียวกันได้)
