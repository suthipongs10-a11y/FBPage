# ห้องข่าว (Newsroom) — เพจข่าวแบบ "หาข่าว → AI คัด → AI เขียน → อนุมัติ 1 คลิก"

เพิ่มเมื่อ 26 กันยายน 2026 · เมนู **ห้องข่าว** (`/news`) · โค้ด: `packages/web-core/src/news.ts`, `apps/api/src/news`, `apps/web/app/(app)/news`

## การไหล

```
แหล่งข่าวของแบรนด์ (RSS / คำค้นผ่าน Tavily)
  → ดึงข่าว: เก็บแค่หัวข้อ + เกริ่นสั้น + ลิงก์ต้นทาง (ไม่เก็บเนื้อหาเต็ม ไม่เก็บรูป)
  → กันซ้ำ: URL มาตรฐาน (ตัด utm/www/fragment) + หัวข้อที่ normalize แล้ว ภายใน 14 วัน · ข่าวเก่ากว่า 7 วันไม่เก็บ
  → AI บทบาท research คัดข่าวน่าสนใจ ให้คะแนน 0–100 ระบุหมวดและความเสี่ยง
  → AI บทบาท content เขียนโพสต์ใหม่ด้วยสำนวนของเพจ + ข้อความบนการ์ด
  → ระบบต่อท้าย "ที่มา: <สำนักข่าว> + ลิงก์" ให้เองทุกโพสต์ → เรนเดอร์การ์ดหัวข่าว (เทมเพลต news)
  → ส่งเข้าคิวรออนุมัติ (READY_FOR_APPROVAL) — ไม่โพสต์เองเด็ดขาด
  → คนกด "อนุมัติและตั้งเวลา" (POST content/:id/approve-schedule) → คิวเผยแพร่เดิม
```

## ตั้งค่าครั้งแรก
1. ผูกเพจกับแบรนด์ (หน้า **เพจ**) — ห้องข่าวใช้แบรนด์ที่มีเพจเท่านั้น
2. หน้า **โมเดล AI**: ตั้งบทบาท **research** (คัดข่าว) และ **content** (เขียนโพสต์) จะชี้คนละเจ้าก็ได้ เช่น research = OpenAI รุ่นถูก, content = Claude — หรือเลือกรายครั้งในหน้าห้องข่าว (dropdown "AI ที่ใช้คัด/เขียน")
3. หน้า **ห้องข่าว** → เพิ่มแหล่งข่าว:
   - **RSS** — ลิงก์ RSS ของสำนักข่าว (ฟรี ไม่ต้องมีคีย์)
   - **คำค้นเว็บ** — ต้องตั้งคีย์ Tavily ก่อน (สมัครฟรีที่ tavily.com ประมาณ 1,000 ครั้ง/เดือน) คีย์เข้ารหัสเก็บฝั่งเซิร์ฟเวอร์ ไม่แสดงกลับ
4. กด **ดึงข่าวตอนนี้** → **ให้ AI คัดข่าว** → เลือกเพจ → **ให้ AI เขียนโพสต์** → ตรวจ → **อนุมัติและตั้งเวลา**

## กฎที่ระบบบังคับ
- **เขียนใหม่ทั้งหมด** ห้ามคัดลอกประโยคต้นทางเกิน 8 คำติดกัน · ใช้ข้อเท็จจริงจากข้อมูลที่ดึงมาเท่านั้น
- ไม่แน่ใจ → AI ใส่ `[ต้องยืนยัน: ...]` → **ปุ่มอนุมัติ+ตั้งเวลาถูกปิดจนกว่าจะแก้ข้อความ** (API ตอบ 422 และไม่เปลี่ยนสถานะครึ่งทาง)
- ข่าวอาชญากรรม: ห้ามระบุชื่อบุคคลธรรมดา ใช้ "ผู้ต้องหา/ผู้เสียหาย" ห้ามตัดสินว่าใครผิด
- ป้าย **เสี่ยง** (HIGH): อาชญากรรม การเมือง สถาบันฯ ศาสนา สุขภาพ การเงิน ระบุตัวบุคคล ข่าวลือ ภัยพิบัติที่มีผู้เสียชีวิต — ต้องอ่านทวนเสมอ
- **ไม่ใช้รูปของสำนักข่าว** — ภาพประกอบคือการ์ดตัวอักษรที่ระบบสร้างเอง (ภาพ AI เชิงสัญลักษณ์: เฟสถัดไป)
- ดึงเว็บอย่างสุภาพ: UA ระบุตัว, เคารพ robots.txt, ≤ 1 คำขอ/วินาที, timeout, เพดาน 2 MB, กัน SSRF ทุก redirect

## ภาพถ่ายจริงจากคลังภาพฟรี (Pexels) — ค่าเริ่มต้นที่แนะนำ
- ตั้งคีย์ที่หน้าห้องข่าว (สมัครฟรีที่ pexels.com/api) · เลือก "ภาพประกอบ: ภาพถ่ายจริง (Pexels)"
- AI เขียน `photoQuery` ภาษาอังกฤษ (สิ่งของ/สัตว์/สถานที่ ห้ามชื่อคน) → ค้น Pexels → ดาวน์โหลด (กัน SSRF, ตรวจไบต์ว่าเป็นภาพจริง, เพดาน 12 MB)
- โพสต์ได้ **2 รูป**: รูปแรกการ์ดหัวข่าวที่ใช้ภาพถ่ายครึ่งบน + ป้ายเครดิตช่างภาพ, รูปที่สองภาพถ่ายเต็มใบ · ต่อท้ายโพสต์ "ภาพประกอบ: <ช่างภาพ> / Pexels"
- ภาพเป็น **ภาพบรรยากาศเรื่อง ไม่ใช่ภาพจากเหตุการณ์จริง** — ห้ามใช้รูปของสำนักข่าวเด็ดขาด
- คีย์ผู้ให้บริการภายนอกเก็บใน `SearchProviderAccount` ต่อ (workspace, provider): `tavily` | `pexels`

## ภาพจาก AI (N-3)
- ตั้งที่หน้า **โมเดล AI → ภาพจาก AI**: เลือกคีย์ที่ใส่ไว้แล้ว (OpenAI / Gemini / OpenRouter / compatible) + ชื่อโมเดลภาพ เช่น `gpt-image-1`, `gemini-2.5-flash-image` — **Claude สร้างภาพไม่ได้**
- ราคาต่อภาพกรอกเอง (ไม่กรอก = "ไม่ทราบค่าใช้จ่าย" ไม่ใช่ $0) · **เพดานภาพต่อเดือนแยกจากงบข้อความ** ครบแล้วตอบ 402
- ในห้องข่าวติ๊ก **ใส่ภาพ AI ในการ์ด** → AI เขียน `imagePrompt` (ภาษาอังกฤษ เชิงสัญลักษณ์) → ระบบต่อท้ายคำสั่งกัน "ห้ามคนจริง/ตัวอักษร/โลโก้/ภาพเหมือนภาพข่าว" เสมอ → การ์ดครึ่งบนเป็นภาพ + ป้าย **"ภาพประกอบจาก AI"**
- สร้างภาพไม่สำเร็จ → ยังได้ร่างพร้อมการ์ดตัวอักษร และแจ้งเหตุ · ทุกครั้งบันทึก `MediaJob` (รวมที่ล้ม) · `MediaAsset.aiGenerated = true`
- API: `GET/PUT media/ai-config`, `POST media/ai-image { prompt, contentId?, attach, modelOverride?, idempotencyKey? }`

## อัตโนมัติ (N-4)
- ตั้งต่อแบรนด์ในหน้าห้องข่าว: เพจ, ดึงทุก N ชม., ร่างต่อวัน, คะแนนขั้นต่ำ, ข้ามข่าวเสี่ยง, ใส่ภาพ AI, ธีม, **ช่องเวลาโพสต์**
- ทุก 5 นาที API ตรวจแบรนด์ที่ถึงรอบ (กันรันซ้อนด้วย Redis lock) → ดึง → AI คัด → เขียนร่างจนครบโควตาของวัน (นับตามเขตเวลา workspace)
- **ไม่โพสต์ ไม่ตั้งเวลาเอง** — ร่างเข้าคิวรออนุมัติ และแจ้งเตือนตามปกติ · สวิตช์ฉุกเฉิน `automationPaused` หยุดทุกแบรนด์ · ปิดทั้งระบบด้วย `NEWS_AUTOMATION_ENABLED=false`
- ตอนกดอนุมัติ ช่องเวลาเริ่มต้น = **ช่องว่างถัดไปของเพจ** (`GET news/next-slot?pageId=`) ไม่ชนโพสต์ที่ตั้งเวลาไว้แล้ว
- ร่างที่ระบบสร้างบันทึกในนามคนที่เปิดอัตโนมัติ (audit) · หยุดเขียนต่อทันทีเมื่อเจองบ AI หมด/ยังไม่ตั้ง AI
