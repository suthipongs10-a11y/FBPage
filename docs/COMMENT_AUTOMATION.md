# ดูแลคอมเมนต์อัตโนมัติ — ไลค์ / ตอบ / ส่งรายละเอียดเข้าแชท

เพิ่มเมื่อ 28 กันยายน 2026 · หน้า **คอมเมนต์** → เลือกเพจ → การ์ด "ดูแลคอมเมนต์อัตโนมัติ (เพจนี้)"

## ทำอะไร

ทุก 3 นาที (`CommentAutomationService`, ล็อก Redis `comment-automation:lock`, ทีละเพจ):
1. ซิงก์คอมเมนต์ใหม่ (ถ้าซิงก์ล่าสุดเกิน 5 นาที)
2. AI จำแนก (บทบาท `community`) — เฉพาะคอมเมนต์ที่ **เข้ามาหลังกดเปิด** (`enabledAt`) ไม่ย้อนไปคอมเมนต์เก่า ไม่เสียค่า AI กับของเก่า
3. ทำตามสวิตช์ของเพจ:

| สวิตช์ | ใช้กับ | ทำอะไร |
|---|---|---|
| ส่งรายละเอียดเข้าแชท (`autoPrivateReply`) | LEAD / PRICE_QUERY / SERVICE_QUERY / QUESTION | ส่งข้อความที่ AI ร่างจากข้อมูลแบรนด์เข้าอินบ็อกซ์ของคนคอมเมนต์ (private reply) + ตอบใต้คอมเมนต์ด้วย `publicAckText` เช่น "ส่งรายละเอียดให้ทางแชทแล้วนะคะ 😊" |
| ตอบใต้คอมเมนต์ (`autoReply`) | คำถามทั่วไป / คำชม | ตอบใต้คอมเมนต์ด้วยร่างของ AI |
| กดไลค์ (`autoLike`) | คอมเมนต์เชิงบวก/คำถาม | ไลค์คอมเมนต์ |

ลำดับต่อคอมเมนต์: ส่งแชท (+ตอบรับ) → ตอบ → ไลค์ แล้วตั้ง `autoHandledAt` — ไม่ทำซ้ำ

## ไม่แตะ (รอคน)

- คอมเมนต์ที่ AI ติดธงเสี่ยง (`riskFlag`), sentiment เชิงลบ, คำตำหนิ, สแปม
- คอมเมนต์ของเพจเอง (`fromId` = เพจ)
- เพจ/พื้นที่ทำงานกด **หยุดระบบอัตโนมัติ** → ข้ามรอบ (ไม่ตั้ง handled จะทำต่อเมื่อปลด)
- โหมด `FULL_AUTO` เดิมของเพจยังตอบใต้คอมเมนต์ได้เหมือนเดิม

## กดเองรายคอมเมนต์

- 👍 **ไลค์** — `POST comments/:id/like`
- 💬 **ส่งเข้าแชท** — `POST comments/:id/private-reply` `{ message?, publicAck?: string | null }` (null = ไม่ตอบใต้คอมเมนต์) · แก้ร่าง `privateReplyText` ได้ด้วย `PATCH comments/:id`
- ตั้งค่า: `GET/PUT pages/:pageId/comment-automation`, ทำรอบทันที `POST pages/:pageId/comment-automation/run`

## กฎของ Meta ที่ระบบบังคับ

- Private reply ได้ **ครั้งเดียวต่อคอมเมนต์** และภายใน **7 วัน** หลังคอมเมนต์ (เกิน → 422, ส่งแล้ว → 409)
- ต้องมีสิทธิ์: อ่านคอมเมนต์ `pages_read_user_content`, ไลค์/ตอบ `pages_manage_engagement`, ส่งแชท `pages_messaging` — ไม่มีจะขึ้นข้อความบอกว่าขาดสิทธิ์ไหน (ไม่พยายามแก้เอง)
- หลังคนนั้นตอบกลับในแชท บทสนทนาจะเข้า **แชทอัตโนมัติ** ตามปกติ (ดู `docs/MESSENGER.md`)

## ปิดทั้งระบบ

`COMMENT_AUTOMATION_ENABLED=false` ใน `.env` ของ API (ค่าเริ่มต้น true — แต่ทุกเพจเริ่มต้นปิด ต้องกดเปิดรายเพจ)
