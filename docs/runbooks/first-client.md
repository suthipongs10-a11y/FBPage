# Runbook — รับงานลูกค้ารายแรกด้วยระบบใหม่ (ครบลูป §100)

> ใช้ได้ทันทีด้วย user token ที่มีอยู่ (ไม่ต้องมีแอป Meta) — ทุกขั้นมี audit log และไม่มีอะไรโพสต์ลงเพจจริงโดยไม่ผ่านการอนุมัติ

## 0. เปิดระบบ
```
cp env.example .env           # กรอก AUTH_SECRET (≥32 ตัว), DATABASE_URL, REDIS_URL
pnpm install && pnpm db:migrate && pnpm build
pnpm dev:api    # :4000   pnpm dev:web  # :3000   pnpm dev:worker  # จำเป็นสำหรับโพสต์ตามเวลา + ซิงก์รอบ 6 ชม.
```
หรือ `docker compose up -d` (มี Chromium + ฟอนต์ไทยในอิมเมจ API แล้ว)

## 1. บัญชีและลูกค้า
1. `/register` → ได้ workspace แรก (คุณเป็น owner)
2. **ลูกค้า** → เพิ่มลูกค้า → เพิ่มแบรนด์ → กรอก **ข้อมูลธุรกิจ** (business_info + brand_voice + service/product อย่างน้อยอย่างละ 1 → สถานะ "พร้อมใช้")
   - ใส่ **ข้อห้ามกล่าวอ้าง** (prohibited_claim) ด้วย เช่น ห้ามอ้างผลทางการแพทย์ — Reviewer ใช้ตรวจทุกโพสต์
   - ราคา/เบอร์/ที่อยู่/เวลาทำการ ถ้าไม่กรอก AI จะไม่เดา แต่จะขึ้น NEEDS_HUMAN_INPUT

## 2. เชื่อมเพจ
1. **เพจ** → วาง user token (จาก Graph API Explorer ที่ extend แล้ว) → "ตรวจสอบและเชื่อมต่อ"
2. เลือกเพจ → เลือกแบรนด์ → "เชื่อมเพจ" → ระบบดึงโพสต์ 90 วัน + metric ทันที
3. ในหน้าเพจ: ดูคะแนนข้อมูลครบ, สิทธิ์ (ต้องมี CREATE_CONTENT ถึงโพสต์ได้), ตั้ง **ระดับอัตโนมัติ** (ค่าเริ่มต้น "ต้องอนุมัติก่อนโพสต์")
   - token หมดอายุ → วาง token ใหม่ในหน้าเพจ ระบบต่ออายุ page token ให้ทุกเพจใต้บัญชีนั้นเอง

## 3. ตั้งค่า AI (ครั้งเดียวต่อ workspace)
**โมเดล AI** → ใส่ API key ของผู้ให้บริการที่มี (anthropic / openai / gemini / openrouter / compatible เช่น Groq) → "ทดสอบ" → กำหนดบทบาท:
- strategy (วางแผน) และ analysis (วิเคราะห์/รายงาน) → โมเดลเก่ง · content (เขียน) → โมเดลกลาง · fast (Reviewer/ตอบเร็ว) → โมเดลถูก · fallback → อีกผู้ให้บริการ
- ตั้ง **งบต่อเดือน** — เกินแล้วระบบตอบ 402 ทันที; ดูค่าใช้จ่ายรายโมเดลในหน้าเดียวกัน

## 4. วิเคราะห์ → วางแผน → ร่าง → อนุมัติ → โพสต์
1. หน้าเพจ → **วิเคราะห์ด้วย AI** (Analyst) → ได้สรุป/รูปแบบ/คำแนะนำพร้อมระดับความมั่นใจ และ "ข้อจำกัดของข้อมูล" (ค่าที่ Facebook ไม่ให้อ่านจะไม่ถูกตีความเป็น 0)
2. หน้าเพจ → **วางแผนคอนเทนต์ด้วย AI** (Strategist) → ได้รายการ "วางแผนแล้ว" ในหน้า **คอนเทนต์**
3. หน้าคอนเทนต์ → แต่ละรายการกด **ให้ AI เขียนร่าง** → ตรวจ `ข้อมูลที่ AI ต้องการจากคุณ` → แก้ข้อความเอง (ทุกการแก้เก็บ revision)
4. **ภาพประกอบ** → "ให้ AI ออกแบบการ์ดภาพ" หรือเลือกเทมเพลตเอง (quote/tips/stat/hero) → รูปแนบเข้าโพสต์อัตโนมัติ
5. **ส่งขออนุมัติ** → Reviewer ตรวจ (PASS / ต้องแก้ / BLOCKED) → เข้าคิวรออนุมัติ
6. **อนุมัติ** (ถ้าคุณเป็นคนอนุมัติเองระบบบันทึกว่า self-approve) → **ตั้งเวลา** (เวลาท้องถิ่นของเพจ, ล่วงหน้า 10 นาที–75 วัน) หรือ **โพสต์ตอนนี้**
   - โพสต์ตามเวลาต้องมี worker รันอยู่ · ปุ่มฉุกเฉิน: หยุดทั้ง workspace (ตั้งค่า) หรือหยุดรายเพจ (หน้าเพจ)
7. **ปฏิทิน** ดูรายสัปดาห์ · ระบบเก็บ metric ของโพสต์ที่ 24 และ 72 ชม. และซิงก์ทุกเพจทุก 6 ชม.

## 5. รายงานให้ลูกค้า
**รายงาน** → เลือกเพจ + เดือน → "สร้างรายงาน" → คัดลอกข้อความส่ง LINE/อีเมลได้ทันที (มีสรุปผู้บริหารโดย AI ถ้าเปิดไว้)
- รายงานบอกตรงๆ ว่าอ่านค่าไหนไม่ได้ (ถูกใจ/คอมเมนต์/การเข้าถึง ต้องผ่าน App Review / read_insights)

## 6. คอมเมนต์และลีด (เมื่อ token มีสิทธิ์อ่านคอมเมนต์)
**คอมเมนต์** → "ซิงก์คอมเมนต์" → "ให้ AI จำแนก + ร่างตอบ" → แก้คำตอบแล้ว "ส่งคำตอบ" (หรือซ่อนสแปม) · ลีดที่ตรวจพบไปที่หน้า **ลีด** เปลี่ยนสถานะ/จดบันทึกได้
- ถ้าขึ้น "token ยังไม่มีสิทธิ์ pages_read_user_content" → เพิ่มสิทธิ์ใน Graph API Explorer แล้ววาง token ใหม่ที่หน้าเพจ
- ตั้ง webhook ของ Meta (ไม่บังคับ): Callback `<API_URL>/facebook/webhook`, verify token = `META_WEBHOOK_VERIFY_TOKEN`, field `feed` → คอมเมนต์ใหม่เข้าระบบเอง

## 7. ทีมและการแจ้งเตือน
- **ตั้งค่า → ลิงก์เชิญสมาชิก**: เลือกบทบาท → สร้างลิงก์ → ส่งทาง LINE (ใช้ครั้งเดียว 7 วัน) · สมาชิกลืมรหัส → กด "สร้างลิงก์ตั้งรหัสใหม่" ข้างชื่อ
- **ตั้งค่า → การแจ้งเตือน**: ใส่ webhook URL (Discord/Slack) แล้ว "ทดสอบส่ง" — จะได้รับ: รออนุมัติ, โพสต์ไม่สำเร็จ, token เพจเสีย, ลีดร้อน, รายงานพร้อม, งบ AI ใกล้หมด

## เมื่อเจอปัญหา
| อาการ | ทำอย่างไร |
|---|---|
| เพจขึ้น "ใช้ไม่ได้" | วาง token ใหม่ที่หน้าเพจ (ห้ามแก้ไขในฐานข้อมูล) |
| โพสต์ไม่สำเร็จ | หน้าคอนเทนต์แสดง "ข้อผิดพลาดล่าสุด" → แก้แล้วกด "กลับไปแก้" → โพสต์ใหม่ (ระบบกันโพสต์ซ้ำด้วย ExternalOperation) |
| AI ตอบ 422 "ยังไม่ได้ตั้งค่า AI" | ใส่ key ที่โมเดล AI |
| AI ตอบ 402 | งบเดือนนี้หมด → เพิ่มงบ |
| สร้างการ์ดไม่ได้ | ตั้ง `CHROME_BIN` ให้ชี้ Chromium (ใน Docker มีให้แล้ว) |
